# Phase 2A.7A Media Engine Upgrade and Backend Plan

Status: design and sequencing only. Nothing in this document authorizes an update, install, proof of concept, packaging run, source edit, browser-picker change, or Phase 2B.

## Gate principles

- Preserve baseline `898e949fb6a04ee439acc555a29b03fe0b54df77`; every implementation phase begins from a clean, reviewed branch and ends at its stopping condition.
- Exact pins and hashes are release inputs. Development may evaluate an upstream nightly only in an isolated disposable environment; releases use an approved stable version.
- No ambient user-site packages, `PATH` tools, global configuration, plugins, arbitrary repositories, or customer self-update may affect a release.
- Each phase runs focused tests first, then `python -m pytest -q` at its final gate. Packaging is run only in a phase that changes packaging/dependency inputs.
- Manual compatibility is never claimed from extractor presence. Protected/DRM workflows remain unsupported. Authenticated support requires the later consent-governance phase.

## Controlled yt-dlp update plan

| Item | Required decision/procedure |
|---|---|
| Current / target | Current imported pip module `2026.03.17`; proposed stable target [`2026.07.04`](https://github.com/yt-dlp/yt-dlp/releases/tag/2026.07.04), verified from the official GitHub `releases/latest` redirect on 2026-07-12. Reconfirm the latest approved stable immediately before the authorized upgrade; do not float the target mid-phase. |
| Integration method | Keep Python-module integration initially. Create an isolated build environment and exact lock/constraints with hashes for `yt-dlp[default]` and the approved optional extras. Import from that environment and freeze that same environment. |
| Why not `yt-dlp -U` | Officially for release binaries. Stratum imports a pip module and never invokes the console launcher. `-U` cannot update an already frozen application and is not reproducible/auditable. |
| Channels | Development: stable by default; a pinned nightly may be evaluated only to diagnose an upstream break, never merged implicitly. Release: exact stable only. Master is excluded. |
| Official source/integrity | PyPI package linked by the official installation docs or official GitHub release/tag. Resolve hashes into the lock; verify package hashes and tag/release provenance. If any official binary is evaluated, verify upstream signed checksum files/public key. |
| Licence | PyPI source/wheel is Unlicense; lock and inventory all extras/transitives separately. Do not substitute the official PyInstaller `yt-dlp.exe` without accepting its documented GPLv3+ combined-work obligations. Generate SBOM/notices. |
| Backup/rollback | Record old lock, wheel cache hashes, build manifest, tests and compatibility results. Tag/commit each approved dependency state. Roll back by rebuilding from the previous lock; never mutate customer binaries in place. |
| Reproducibility | Clean virtual environment, no user site, offline/hash-locked install after artifact acquisition, record Python/PyInstaller/platform versions, inspect frozen contents and runtime version, compare two clean build manifests. |
| Compatibility | Pin a matching `yt-dlp-ejs`; select one governed JS runtime; validate FFmpeg/FFprobe, certifi, Requests, websockets, Brotli, curl_cffi and pycryptodomex decisions. No extra enters merely because it is available globally. |
| Automated gate | Import/version/path tests; no ambient override; extractor fixtures; metadata schema; complete/split A/V; HLS/DASH/CMAF; output templates; collision/path length; pause/cancel/process cleanup; final FFprobe; error redaction; frozen smoke test. Full suite follows. |
| Manual gate | Owned/authorized public fixtures for priority sites in document 15, plus authentication/DRM rejection, browser-to-desktop routing, quality/audio choices and verified output. Record date/version/OS/result; failures block certification. |
| Future updater | Signed Stratum release manifest from one hardcoded first-party endpoint, exact allowed package/build IDs and hashes, staged atomic replacement, health check and rollback. It updates the whole tested backend bundle, never `--update-to` user input or arbitrary repositories. |

Important current gaps that block a credible upgrade: no requirements/lock, user-site import, missing `yt-dlp-ejs`, no enabled governed JS runtime, missing Brotli/curl_cffi/pycryptodomex, GPL-enabled FFmpeg release blocker, and a spec with empty binary/data declarations.

## Controlled gallery-dl plan

- Proposed PoC version: exact **1.32.6** stable from the official Codeberg project/PyPI path, rechecked at authorization time. No nightly/master.
- Integration: optional separate subprocess with an exact executable/environment path and protocol adapter; do not import into the main proprietary process. Begin as development-only and separately distributed/installed unless legal review approves bundled GPL-2.0 compliance.
- Pin gallery-dl and its complete dependency closure with hashes. Disable ambient/user/global/executable-adjacent configuration; private generated config only. Disable remote URL lists, extractor forcing, arbitrary options/templates and plugin/module injection.
- Record official tag/package provenance, artifact hashes, SBOM, GPL licence/source package/build recipe. Legal approval is a stopping gate, not documentation boilerplate.
- Roll forward/back by swapping the entire versioned adapter bundle selected in Stratum's manifest; keep prior bundle and archive-schema compatibility. Tests in Phase D must pass before Phase E.

## Controlled Poppler plan

- Proposed source: exact **Poppler 26.07.0** signed official tarball plus required `poppler-data` version where needed. The official site does not provide an official supported Windows binary; never use random builds.
- PoC must reproducibly build from verified official source or stop. Pin compiler/toolchain, transitive libraries and data; record upstream signature, all hashes, flags, SBOM, GPL-2.0-or-later notices/source/build recipe.
- Begin with `pdfinfo` and one preview renderer (`pdftoppm` or `pdftocairo`). Add `pdftotext`, `pdfimages`, `pdfseparate`, or `pdfunite` only when its feature phase is authorized and its dependency/size/security cost is measured.
- The versioned worker bundle is rolled back atomically as a unit. Malformed/password/bomb/timeout/process-tree/output-validation fixtures and legal approval block Phase H.

## Release blockers carried forward

1. Dependency integration is unpinned and uses mutable user-site state.
2. Full modern YouTube support lacks `yt-dlp-ejs` and a governed enabled JS runtime.
3. Repo-local FFmpeg/FFprobe are GPL-enabled, provenance-sensitive development binaries and are not explicitly packaged by the current spec.
4. gallery-dl and Poppler require explicit GPL distribution/legal decisions and clean PoCs; neither is installed.
5. Current browser page recognition and player ownership are too narrow for broad social compatibility claims.
6. No site is certified by this documentation audit; every matrix entry remains untested in Stratum unless a prior dated manual record says otherwise, and none was newly tested here.
